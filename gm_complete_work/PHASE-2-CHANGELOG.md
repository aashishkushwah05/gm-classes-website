# GM Classes — Phase 2: Premium Home Page

## Scope
This phase upgrades the homepage visual design while preserving the existing Next.js app structure, routes, source-of-truth site configuration, and verified content.

## Changes
- Rebuilt the hero into a stronger editorial-style layout with a large headline, restrained gold highlight, admissions CTA, WhatsApp CTA, and factual class/board/medium details.
- Added a fine-grid background, soft gold ambient orbs, layered institute image treatment, and a floating concept-first learning card.
- Highlighted the 7-day free demo without adding fabricated performance statistics or testimonials.
- Added hover depth and gold edge treatments to homepage content cards.
- Replaced scarcity wording in the final contact CTA with a neutral invitation.
- Preserved responsive layout and reduced-motion behavior.
