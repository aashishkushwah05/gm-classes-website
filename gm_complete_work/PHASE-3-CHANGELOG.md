# GM Classes — Premium UI & Motion Phase 3

## Scope
Premium polish for inner pages, built on the Phase 2 ZIP. Existing routes, verified content, forms, course data, faculty/result data, SEO metadata, structured data, and WhatsApp enquiry flows are preserved.

## UI updates
- Added a consistent editorial-style page hero treatment to inner-page landing sections, with warm neutral gradients and restrained gold lighting.
- Standardized hero heading rhythm, readable text widths, eyebrow labels, and responsive spacing.
- Added refined hover/focus states for interactive cards, filter controls, and content panels.
- Improved course explorer, faculty/result cards, FAQ explorer, blog listings/article reading width, and enquiry panel visual consistency using scoped CSS.
- Added responsive adjustments for compact screens and respects `prefers-reduced-motion`.
- No new packages added and no new factual/marketing claims introduced.

## Included pages
Courses, course details, Faculty, Results, About, Admissions, Contact, FAQ, Blog listing, and Blog articles.

## Validation
Source-level checks and ZIP integrity are performed during packaging. Run `npm install`, `npm run typecheck`, `npm run lint`, and `npm run build` on the target PC before treating the phase as production-verified.
